## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- Git

### Clone the repository

```bash
git clone https://github.com/Kiruthickrosan/prism-code-port.git
```

### Navigate into the project

```bash
cd prism-code-port
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown by Vite.

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

## 🎨 Design Philosophy

The portfolio follows a **professional light developer/SaaS aesthetic** rather than a gaming or cyberpunk style.

The design uses:

- Clean white surfaces
- Soft gray backgrounds
- Indigo and violet accents
- Subtle gradients
- Interactive 3D elements
- Controlled motion
- Responsive layouts
- Clear typography and visual hierarchy

Animations are designed to enhance the experience without distracting from the content.
